# water-quality-monitoring-device-selection-data
Dataset for device selection of water quality monitoring systems.

## Overview

This repository provides the raw device dataset used for the study on device selection and system-level configuration of water quality monitoring systems.

The dataset contains technical specifications and cost information for candidate devices considered in the study. Data were collected from publicly available manufacturer specifications, product documentation, and related commercial information during September–October 2025.

## Dataset

The dataset is provided in:

- `Device_Selection_Raw_Data.xlsx`

The workbook contains 15 worksheets covering the following device categories:

1. Dissolved oxygen sensors
2. Chlorophyll sensors
3. Ammonia nitrogen sensors
4. Suspended solids sensors
5. Chemical oxygen demand sensors
6. Electrical conductivity sensors
7. pH sensors
8. Turbidity sensors
9. Controllers
10. BeiDou satellite communication devices
11. LoRa communication devices
12. 4G communication devices
13. NB-IoT communication devices
14. Cloud platforms
15. Power supply devices

## Data Description

For each candidate device, the dataset includes available information such as:

- Manufacturer
- Model
- Technical specifications
- Environmental and operating characteristics
- Communication or interface characteristics
- Power-related characteristics
- Cost

The specific indicators differ according to device category.

Prices were collected during September–October 2025 and are reported in RMB unless otherwise specified.

## Data Sources

The dataset was compiled from publicly available manufacturer specifications, technical documentation, product information, and commercial sources. Product specifications and prices represent the information available during the data collection period and may change over time.

## Purpose

The dataset was developed to support device-level evaluation and system-level configuration optimization for water quality monitoring systems.
